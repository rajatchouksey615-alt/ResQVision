# Dataset Storage Policy

This repository does not contain datasets. Do not commit large datasets, private CCTV recordings, real incident footage, personal data, or data whose licensing and permitted use have not been reviewed.

Before using a dataset, document its provenance, license or terms, privacy review, permitted purposes, retention constraints, and any preprocessing. Prefer approved, appropriately licensed public or synthetic data. Keep downloaded data in a local or separately governed storage location; dataset files are ignored by Git.
