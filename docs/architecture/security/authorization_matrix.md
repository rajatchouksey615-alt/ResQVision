## Interpretation and Approval Notes

- `PROPOSED` can describe an existing enabled code path as a draft requirement implementation; it does not mean stakeholders approved the permission.
- `BLOCKED` describes a deliberately unavailable policy/route. A 503 policy-unavailable response is not an authorization grant or a resource-existence signal.
- Out-of-scope incident/assignment reads currently use scoped querysets and 404 concealment. Do not generalize that response to unresolved-policy routes, which return 503 before resource lookup.
- Source owner/operator is not an application role. The designated Police reviewer and assignment-authority boundaries are owner-approved, but the existing backend mechanism and candidate scope binding remain unresolved. Audit reader, location steward, and evidence custodian do not receive permissions from these decisions.
