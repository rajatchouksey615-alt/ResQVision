# Project Overview

ResQVision (AI-Based Road Accident Detection and Emergency Response System) is an academic major project for a team of four. It explores a modular system that could analyze CCTV or video for potential road accidents, verify candidates, create incident records and evidence metadata, and provide role-based views for Admin, Police, and Hospital users.

Planned modules are a Flutter and Dart mobile app, a Python/Django REST backend with PostgreSQL, a Python AI service using YOLO and computer-vision tooling, supporting infrastructure, and technical documentation. The repository is in Phase 0; these components are not implemented.

The prototype will not send real emergency alerts, dispatch ambulances, or integrate with emergency organizations unless explicitly authorized. Detection is not confirmation; verification logic and review are required. Map and object storage providers remain pending.
