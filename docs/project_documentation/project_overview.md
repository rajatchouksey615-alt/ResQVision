# Project Overview

ResQVision (AI-Based Road Accident Detection and Emergency Response System) is an academic major project for a team of four. It explores a modular system that analyzes approved CCTV or video for potential road accidents, verifies candidates, manages incident records and evidence metadata, and provides role-based views for Admin, Police, and Hospital users.

The project is in **Phase 1 — Requirements Engineering and System Design**. This repository phase is producing a reviewable specification; the Flutter/Dart mobile app, Python/Django REST backend, PostgreSQL schema, Python AI service, and supporting infrastructure remain unimplemented.

The prototype will not send real emergency alerts, dispatch ambulances, or integrate with emergency organizations. Detection is not confirmation; candidates require temporal verification and authorized human review under a policy still to be approved. Map, object storage, deployment, model, and other provider choices remain pending.

See the [system requirements specification](../requirements/system_requirements_specification.md), [system architecture](../architecture/system_architecture.md), and [open architecture decisions](../architecture/open_architecture_decisions.md).
