# Testing Documentation

**Status:** REVISED_DRAFT — pending team approval.

This directory describes the proposed Phase 1 testing approach. The backend has executable PostgreSQL-backed model tests for accounts, audit, organizations, video sources, detection, candidates/incidents, locations, evidence, responses, and notifications. The current full backend suite passes 50 tests. API authorization, service transaction/concurrency, object-storage fault, Flutter, AI-evaluation, and end-to-end tests remain future work.
